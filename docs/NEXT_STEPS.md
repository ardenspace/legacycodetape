## 목표와 합의

Legacy Code Tape는 소프트웨어·하드웨어·기계를 아우르는 개발자의 플레이리스트 채널이다. 여러 시대와 공간의 작업실로 확장할 수 있지만 첫 시도는 80~90년대 SF 셀 애니메이션 감성과 로파이다.

- 음악은 사용자가 구독 중인 Suno에서 제작한다.
- 제목은 음악과 분위기를 바로 이해할 수 있게 쓴다. 세계관을 넣는다면 설명란에 둔다.
- 고정 레이아웃, 주인공, 테이프 번호, 서사형 제목은 확정하지 않았다. 이전 대화의 의수 보정·심해·1994년 설정 등은 예시이며 채택한 기획이 아니다.
- 첨부된 두 레퍼런스에서 짙은 남색·보라색 그림자, 청록 CRT, 작은 빨간 표시등, 셀 명암, 낡고 복잡한 장비의 질감을 참고한다.
- GPT 이미지 생성도 사용한다. Gemma는 장면 프롬프트 작성 역할로 연결했다.
- 정지 이미지 위에 투명한 웹 효과 레이어를 겹치는 방식부터 시도한다. 인물 애니메이션과 Blender/Three.js 도입은 필수가 아니다.
- 이 웹 프로젝트는 우선 제작·미리보기 도구다. 공개 채널 사이트, 호스팅, 배포 여부는 미정이다.

## 1. 첫 이미지 제작과 선택

- [ ] 기존 프롬프트 후보를 보고 한 장면을 선택하거나 수정한다.
- [ ] 선택한 프롬프트와 필요한 레퍼런스를 실제 이미지 생성 단계에 전달한다.
- [ ] 16:9 구도를 출발점으로 원본 이미지를 생성하고 검토한다. 구도는 고정하지 않는다.
- [ ] 인물·손·장비의 오류, 원치 않는 글자, 질감·색감, 오래 보기 편한지를 확인한다.
- [ ] 움직일 CRT나 표시등을 골라 화면 가림과 원근을 확인한다. 필요하면 해당 부분만 수정한다.
- [ ] 채택 이미지, 실제 사용 프롬프트, 참조 파일, 수정 내역과 선정 이유를 함께 기록한다.

완료 기준: 웹 효과 실험에 사용할 이미지 한 장과 그 제작 기록이 있다. Gemma가 작성한 프롬프트의 장점은 결과를 보고 판단하며, 일관성을 보장한다고 가정하지 않는다.

## 2. 웹에서 이미지와 효과 미리보기

- [ ] 프로젝트에 맞는 최소 웹 구성을 선택하고 새 dev 포트의 점유를 확인한다.
- [ ] 채택 이미지를 불러와 비율을 유지하며 표시한다.
- [ ] 이미지 위에 투명 효과 레이어를 겹친다.
- [ ] CRT 하나의 영역을 지정해 파형 또는 스캔 효과를 적용한다.
- [ ] 필요하면 네 모서리 원근 맞춤·마스크·기존 화면 지우기를 추가한다.
- [ ] 표시등의 약한 점멸을 추가하고 효과별 켜기/끄기·속도·강도를 조절한다.
- [ ] 원본/효과 비교, 재생/일시정지, 조절 UI를 숨긴 출력용 보기를 제공한다.
- [ ] 이미지 기준 좌표와 설정을 저장·불러와 화면 크기가 바뀌어도 위치가 유지되게 한다.

완료 기준: 한 이미지에서 화면과 표시등이 자연스럽게 움직이고, 설정을 다시 불러올 수 있다. 우선 한 장면을 제대로 만든 뒤 범용 영역 편집기로 확장할지 결정한다.

첫 효과 후보는 CRT 파형과 표시등이다. 그레인·먼지·빛 변화는 필요할 때 추가한다. 장면 속 장비를 흉내 낸 파형과 음악에 실제 반응하는 오디오 시각화는 구분하며, 오디오 연동은 아직 확정하지 않았다.

## 3. Suno 음악을 붙인 짧은 샘플

이미지·웹 작업과 병행할 수 있다.

- [ ] 선택한 이미지의 분위기에 맞는 음악 지침을 작성한다.
- [ ] 사용자가 Suno에서 음악 후보를 만들고 파일을 가져온다. 초기에는 수동 흐름으로 충분하다.
- [ ] 음악과 화면을 함께 보며 에너지, 음색, 시각 효과 강도를 조절한다.
- [ ] 필요할 때만 환경음을 별도 레이어로 추가한다.
- [ ] 1~2분 샘플을 제작한다. 음악 반응 효과가 필요하면 이 단계에서 판단한다.

완료 기준: 사용자와 함께 보고 들을 수 있는 짧은 샘플이 있으며, 긴 영상으로 늘릴지 또는 이미지/음악을 수정할지 판단할 수 있다.
